# 安装与使用

## 一键安装

在仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

脚本按以下优先级选择 Codex 根目录：

1. 参数 `-CodexHome` 指定的目录。
2. 环境变量 `$env:CODEX_HOME`。
3. `$env:USERPROFILE\.codex`。

指定目录示例：

```powershell
.\scripts\install.ps1 -CodexHome 'D:\MyCodex'
```

默认不会覆盖已有目录。只有目标目录中的 `pet.json` 仍声明 `id=xiaocheng` 时，才允许使用 `-Force` 覆盖：

```powershell
.\scripts\install.ps1 -Force
```

可以先用 `-WhatIf` 查看目标，不写入文件：

```powershell
.\scripts\install.ps1 -WhatIf
```

## 在 Codex 中启用

1. 打开 ChatGPT 桌面端。
2. 进入 **Settings → Pets**。
3. 点击 **Refresh**。
4. 选择“小澄·薄荷助手”。
5. 如需唤醒悬浮宠物，使用 `/pet` 或命令菜单中的 **Wake Pet**。

## 手动安装

将 `pet/` 中的两个文件复制到：

```text
%CODEX_HOME%\pets\xiaocheng\
├── pet.json
└── spritesheet.webp
```

未设置 `CODEX_HOME` 时，默认位置通常是：

```text
%USERPROFILE%\.codex\pets\xiaocheng\
```

## 卸载

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\uninstall.ps1
```

卸载脚本只会删除路径为 `pets\xiaocheng` 且清单 ID 确认是 `xiaocheng` 的目录。可以使用 `-WhatIf` 预览操作。

## 常见问题

- **Pets 中看不到小澄**：确认两个文件位于同一 `xiaocheng` 文件夹，然后点击 **Refresh**。
- **脚本拒绝覆盖**：先确认目标确实是小澄，再添加 `-Force`；脚本不会覆盖其他宠物。
- **减少动画**：系统开启“减少动态效果”时，Codex 会使用待机状态的静态帧。
