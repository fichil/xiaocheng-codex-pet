# 制作与验证

## 角色基准

小澄是成年 Q 版二次元助手：银蓝短发、青绿色眼睛、奶油白与薄荷青连帽裙、左耳单侧耳麦。画风采用清晰深色轮廓、柔和纯色块和克制高光，确保缩小到 `192×208` 后仍可辨识。

`source/references/canonical-base.png` 是全部动作行的身份基准；`source/prompts/` 保存基础提示词、九个状态提示词及对应重试提示词。

## 图集契约

- 画布：`1536×1872`。
- 网格：8 列 × 9 行。
- 单格：`192×208`。
- 格式：RGBA WebP。
- 未使用单格：完全透明。

## 生成与修复过程

1. 分别生成九个动画状态，每个动作行绑定基准图与布局参考。
2. `running-left` 因左耳单侧耳麦不对称而单独生成，不使用镜像派生。
3. 初次视觉 QA 发现品红边缘色溢和左向耳麦侧别错误。
4. 重新生成左向移动行，将耳麦固定在角色解剖学左耳。
5. 所有动作条带先执行软遮罩、去色溢和 1 像素边缘收缩。
6. 使用 `stable-slots` 保持行内统一比例，消除跳跃动作的抽帧尺寸跳变。
7. 重新合成图集、生成九个 GIF，并完成第三次独立视觉 QA。

## 最终验证

- 图集：WebP、RGBA、`1536×1872`。
- 透明像素 RGB 残留：0。
- 帧数：`6/8/8/4/5/8/6/6/6`。
- 几何错误：0。
- 视觉 QA：通过。
- 验证重点：身份、左耳耳麦、方向、交替步态、动作语义、完整循环、无裁切、无品红残边、无尺寸跳变。

脱敏后的机器可读结果位于 `source/qa/qa-summary.json` 与 `source/qa/visual-qa.json`。

## 可复现性说明

生成式图像工具无法保证再次运行提示词时得到像素级相同结果。本仓库同时保留最终宠物包、基准图、提示词和 QA 记录，以便继续维护角色一致性；确定性的图集尺寸和透明度要求应始终保持不变。
