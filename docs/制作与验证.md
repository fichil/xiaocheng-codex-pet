# 制作与验证

## 角色基准

小澄是成年 Q 版二次元助手：银蓝短发、青绿色眼睛、奶油白与薄荷青连帽裙、解剖学左耳单侧耳麦。画风采用清晰轮廓、柔和纯色块和克制高光，确保缩小到 `192×208` 后仍可辨识。

`source/references/canonical-base.png` 是全部动作的身份基准；`source/prompts/` 保存基础提示词、九个标准状态提示词和 V2 观察方向提示词。

## V2 图集契约

- 画布：`1536×2288`。
- 网格：8 列 × 11 行。
- 单格：`192×208`。
- 格式：RGBA WebP。
- 清单：必须包含 `spriteVersionNumber: 2`。
- 未使用单格：完全透明，透明像素中不保留隐藏 RGB。

前九行沿用小澄 V1 已验证的动画；第 9、10 行（从 0 开始计数）增加 16 个每隔 22.5 度的顺时针观察方向：

```text
000, 022.5, 045, 067.5, 090, 112.5, 135, 157.5,
180, 202.5, 225, 247.5, 270, 292.5, 315, 337.5
```

其中 `000` 为向上，`090` 为屏幕向右，`180` 为向下，`270` 为屏幕向左。

## 生成与修复过程

1. 复用已经通过视觉 QA 的九行标准动画，不重新改变角色身份或动作语义。
2. 生成四个方向基准，再分别生成两条完整、连贯的八方向动作条；不允许单格拼补最终图集。
3. 观察动作以眼睛先动、眼睑与眉毛配合、头颈随后转向、上半身克制跟随的方式表达，禁止旋转整个角色。
4. 每条完整方向动作统一进行比例、基线和脚底锚点校准，保持左耳耳麦的解剖学侧别与自然遮挡关系。
5. 图集只执行一次确定性的品红色溢清理，并清零透明像素中的隐藏 RGB。
6. 生成标准联系表、V2 联系表、16 方向检查图、连续性报告和十个 GIF 动画预览。
7. 三名互相隔离的评审者只查看无角度标签的 A/B 图，按严格多数表决检查水平与垂直方向；四个基准方向是不可跳过的硬门槛。
8. 最后由独立视觉 QA 同时检查九种动画、16 方向有序循环、身份、耳麦、比例、透明度和动作语义。

## 最终验证项目

- WebP、RGBA、`1536×2288`、8×11 网格。
- `spriteVersionNumber: 2`。
- 标准帧数：`6/8/8/4/5/8/6/6/6`。
- 观察方向：16 个，固定顺时针顺序。
- 透明像素 RGB 残留：0。
- 未使用格：完全透明。
- 四个基准方向：盲测硬门槛。
- 中间方向：逐方向语义、盲测提示和有序循环联合复核。
- 连续性：相邻方向无可见反转、缩放跳变、基线跳动或身份漂移。
- 视觉重点：左耳耳麦、脸型、发色、服装轮廓、动作语义、无裁切、无品红色块和多余特效。

脱敏后的机器可读结果位于 `source/qa/`。这些文件不包含本机绝对路径、临时生成目录或凭据。

## 可复现性说明

生成式图像工具无法保证再次运行提示词时得到像素级相同结果。本仓库同时保留最终宠物包、基准图、提示词、方向机制约定和 QA 摘要，便于继续维护角色一致性；确定性的图集尺寸、透明度、方向顺序和 V2 清单要求应始终保持不变。
