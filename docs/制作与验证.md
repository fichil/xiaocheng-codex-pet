# 制作与验证

## 角色与制作方式

小澄是温柔灵动的成年 Q 版助手。新版以柔和哑光 3D 手办形象为统一参考，保留银蓝短发、青绿色眼睛、奶油白/薄荷连帽裙及角色解剖学左耳单侧耳麦。最终交付仍为透明精灵图集。

source/references/canonical-base.png 是所有动作的身份和材质基准；source/prompts 保存主形象、九种标准动作、四方向基准及两条八方向动作的提示词。

## 固定格式

- 图集为 1536×2288、8 列 × 11 行、RGBA WebP；单格 192×208，spriteVersionNumber 为 2。
- 标准帧数为 6/8/8/4/5/8/6/6/6，预览时序沿用原版。
- 第 0 行第 6 列为额外中性姿态；其余未使用格完全透明，透明像素不保留隐藏 RGB。
- 观察方向按 000、022.5、045、067.5、090、112.5、135、157.5、180、202.5、225、247.5、270、292.5、315、337.5 顺时针排列。000 向上，090 向屏幕右，180 向下，270 向屏幕左。

## 动作与抽帧

九种标准动作独立生成，左右移动分别生成以保持耳麦侧别。待机轻微呼吸眨眼，等待输入采用摊手邀请，工作中轻触耳麦思考，审查时双手背后、前倾观察并点头。

初次按独立人物边界缩放时，跳跃的所有帧都被拉到相同高度，导致蹲姿放大、腾空位移消失。保留生成原画并改用 stable-slots：同一动作共享抽帧视窗和尺度，恢复原有纵向位置。这是抽帧修正，不是补画或扭曲人物。

## 观察动作

眼球在眼眶内整体转动，眼睑和眉毛配合，头颈轻转，下身保持锚定。右转时角色左耳处于远侧、耳罩自然被遮挡；左转时左耳位于近侧、耳罩可见。不得把耳罩移到另一耳，也不得旋转整个角色来伪造方向。

先生成并校准四个正方向，再生成第一条八方向动作；第一条的几何、语义及连续性检查通过后，第二条同时参考四方向基准和第一条。失败的方向通过重做所属完整动作条修复。

## 验证证据

- 确定性工具检查尺寸、透明度、边界、使用格与中性姿态，并对完整图集执行一次色溢清理。
- 独立视觉检查关注正常尺寸下的脸型、材质、耳麦侧别、动作语义、循环和跳跃位移。
- 三个隔离评审者仅看随机排列、无方向标签的 A/B 图；按严格多数表决验证方向。四个正方向是硬门槛，中间方向的歧义须结合标注循环复核。
- 连续性数值用于发现疑点；最终是否存在可见跳变、错误象限或反转，由正常尺寸的逐帧及循环检查决定。
- source/qa 中的摘要和逐方向结果通过 SHA256 绑定当前 pet/spritesheet.webp。运行时是否已经刷新显示与磁盘安装验证分开记录。

用户于 2026-09-14 确认已成功切换到新版桌宠，记录见 [QA 摘要](../source/qa/qa-summary.json) 的 runtimeDisplayConfirmation。代理在制作验收时未直接观察实时播放；runtimeDisplayVerified 保留为 false，表示代理观察状态，不否定用户确认。

## 可复现性与维护

生成式工具不能保证重复运行时得到逐像素相同的素材。本仓库保留最终宠物包、基准图、提示词、动作约定及脱敏验证结果。继续维护时须重新验证当前图集，不可把旧素材的 QA 结论移植到新版。

安装备份、原始生成中间文件和完整本机 QA 留在本地输出目录，不属于公开交付内容。仓库素材通过 PR 审查与合并维护；Release 和社区下载站更新另行安排。
